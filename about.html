About

While trying to learn Lebanese Arabic as an English speaker, I couldn't find one single reference or dictionary to look up the actual words spoken in Lebanon - at least not with English characters.

I wanted to build the resource that I could never find, so the purpose of this site is to provide a Lebanese dictionary for English speakers - that others could contribute to. If you want to add or correct words, please feel free to submit a Pull Request on GitHub!
