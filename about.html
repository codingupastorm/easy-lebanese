About

While trying to learn Lebanese Arabic as an English speaker, I couldn't find one single reference or dictionary to look up the actual words spoken in Lebanon - at least not with English characters.

I wanted to build a resource that I could use to look up words, so the purpose of this site is to provide a Lebanese dictionary for English speakers that everyone can contribute to. Naturally, it's a constant work in progress, and reflects my current learnings from the language so far. If you want to add or correct words, please submit a Pull Request on GitHub: github.com/codingupastorm/easy-lebanese.
